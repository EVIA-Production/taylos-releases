# Taylos desktop releases

Official Taylos desktop installers and update manifests for macOS and Windows.

- Product: https://taylos.ai
- Downloads: https://github.com/EVIA-Production/taylos-releases/releases/latest

This repository is a distribution repository. It does not contain the Taylos
application source tree. Installers are compiled software, not source packages.

Use only the signed installers and update assets attached to releases. GitHub's
automatically generated source archives contain this repository's documentation,
not the application.
