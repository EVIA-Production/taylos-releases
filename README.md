# Taylos Desktop Releases

Official signed Taylos desktop installers and update manifests for macOS and Windows.

- Product and downloads: https://taylos.ai
- Latest release: https://github.com/EVIA-Production/releases/releases/latest

This public distribution repository contains release documentation, installers,
and update manifests. Application source is maintained in private repositories.
GitHub's automatically generated source archives contain this repository's
documentation, not the application source tree.
